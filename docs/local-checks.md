# Локальные проверки перед main

Политика обновлена 12 октября 2026 года: GitHub Actions удалены, все проверки
выполняются локально перед каждым обновлением `main`/`master` и перед PR merge.
Основной сайт — `https://zotov.kz` на Hoster.kz. Публикация требует отдельного
разрешения и не выполняется ни hook, ни командой проверки.

```bash
bun install --frozen-lockfile
bun run hooks:install
node node_modules/playwright/cli.js install --only-shell chromium
PUBLIC_WEBSITE_URL=https://zotov.kz PUBLIC_ALLOW_INDEXING=true bun run release:check
```

Bun должен соответствовать `.bun-version`. В Linux Chromium может потребовать
`--with-deps`. Gitleaks впервые скачивается с проверкой закреплённого хеша;
аудит зависимостей требует сети. Ошибка или недоступность любой проверки
останавливает цепочку. Успешный прогон уже включает typecheck и build, повторять
их отдельно после этого не нужно, если код не изменился.

## Что оставлено

| Проверка | Зачем |
| --- | --- |
| Frozen install и installed pins | Воспроизводимая установка; отдельная проверка обнаруживает старые вложенные/workspace-копии закреплённых пакетов, которые нельзя считать проверенными одним lockfile. |
| Bun audit | Известные уязвимости зависимостей и инструментов сборки. |
| Gitleaks: текущие исходники и доступная история | Секреты не должны попадать в Git. Проверка хеша бинарника, ignore-правил и синтетического отклонения выполняется один раз в security gate. |
| SVG scan и короткие отрицательные fixtures | Raw/inline SVG не должен исполнять код, тянуть внешние ссылки или XML entities. Эти fixtures проверяют отклонение опасного входа, а не повторяют скан репозитория. |
| UI ownership и Astro/TypeScript | Сохраняют уже согласованную архитектуру компонентов и обнаруживают ошибки типов. Проверка Storybook/структуры оставлена как существующий контракт из `docs/ui-refactor.md`; сборка Storybook не добавлена в release. |
| Свежая сборка и artifact gate | Canonical, indexing, sitemap, JSON-LD/видимые контакты, CSP, privacy/404 и отсутствие исходников/секретных файлов в output. Отрицательные fixtures защищают сам gate от ослабления. |
| Компактный browser smoke | Мобильное меню, FAQ, карусель, переход CTA в WhatsApp с перехватом без внешнего запроса, контакты, главная/privacy/404, ошибки ресурсов/CSP, контент без JavaScript. Только 390/1440 px; при включённой Метрике — согласие и отзыв согласия. |
| URL/indexing fixtures | Небольшое исключение для unit: опасные origin/path и случайная индексация напрямую влияют на SEO всего сайта. |
| Pre-push integration | Реальный временный Git-репозиторий: destination refs, точный HEAD, грязное дерево, ошибка release, изменения во время проверки, несколько refs, сохранение чужих hooks. Дорогая release-команда заменена локальным fixture. |
| Legacy deploy safety fixtures | Пока команды Cloudflare сохранены, отказ от публикации при ошибке gate или изменении репозитория остаётся важным. |

Это статический frontend без backend, поэтому backend-интеграционные тесты
не добавлены. Unit оставлены только для логики с существенными последствиями;
нет snapshot-тестов компонентов или проверки каждой функции сайта.

## Границы проверки

Hook устанавливается отдельно в каждом клоне. Установщик не заменяет чужой
`pre-push` или `core.hooksPath`; при конфликте подключите `.githooks/pre-push`
вручную и сохраните stdin Git. Остальные hooks не изменяются.

Проверяются именно назначения `refs/heads/main`/`master`, включая `dev:main`.
Отправляемый OID должен совпадать с чистым checkout HEAD до и после проверок;
для нескольких таких refs цепочка запускается один раз. Feature-ветки и удаление
refs не являются release и не запускают цепочку. Перед merge через GitHub нужно
проверить код локально: веб-интерфейс и `--no-verify` обходят локальный hook.

Локальный static server подтверждает работу готовых файлов и браузерных действий.
Он не интерпретирует `.htaccess` и не доказывает корректность Hoster: TLS, 301,
HTTP security/cache headers и настоящий 404 проверяются на домене после
согласованной публикации. Конфигурация находится в `scripts/deploy/hoster.htaccess`.
Старые отчёты в `docs/` описывают состояние на свои даты, текущий процесс — здесь.

## Проверка изменений

12 октября 2026 года полный `release:check` прошёл на локальном macOS с уже
установленными Chromium/Gitleaks и кешем сборки: около **17,5 секунд** по времени
записи лога. Node suite: **50 passed, 0 failed**, примерно 1,17 секунды.
Astro: 94 файла, 0 ошибок/предупреждений. Audit: уязвимости не найдены.
Artifact gate: 188 файлов, 3 страницы. Browser smoke прошёл на 390/1440 px
и без JavaScript; отдельно прошла сборка с синтетическим ID Метрики и проверка
согласия/отказа/отзыва с перехватом запросов. После этого восстановлена
production-сборка без аналитики и повторён artifact gate. ZIP опубликованного
сайта не изменялся. Время прежнего полного процесса заново не измерялось.

Логи исключены из Git: `artifacts/local-checks.log`,
`artifacts/local-checks-analytics.log`, `artifacts/local-checks-restore.log`.

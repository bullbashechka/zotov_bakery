# ZOTOV — UI walkthrough

Открыть `index.html` в браузере. Галерея содержит 51 снимок и фильтры Desktop / Mobile. Нажатие на изображение открывает оригинал. `desktop-full.png` и `mobile-full.png` показывают всю страницу; отдельные кадры показывают состояния компонентов.

Снято 11 сентября 2026 года с локальной текущей реализации: desktop 1440×1000, mobile 390×844. Мобильная версия проверена изменением viewport, без эмуляции конкретной модели телефона и touch-жестов.

## Пользовательский путь

Первый экран и навигация → ассортимент или медовик → сведения о десерте → выбор способа покупки → внешний WhatsApp / 2GIS. FAQ, помощь в выборе и контакты дают дополнительные точки выхода.

Сообщения не отправлялись. Внешние приложения не входят в снимки: адреса и подготовленные тексты запросов приведены внизу галереи. На сайте нет корзины, формы заказа, оплаты и состояний отправки / успешного заказа.

## Состояние реализации

- «Наша история»: только заголовок.
- Юридические страницы: документы находятся в подготовке.
- «Карамельное облако» и «Праздничный букет»: временные описания, состав предлагается уточнять у пекарни.
- Кнопка медовика ведёт в WhatsApp с общим запросом, без названия медовика. Карточки ассортимента передают название выбранного товара.

## Повторная съёмка

`node output/ui-flow/capture.mjs http://localhost:4321`

Нужны уже установленный Playwright и Chrome, а также работающий локальный сайт. В текущем окружении использован Playwright из `C:/Users/fm/node_modules`; зависимости проекта не менялись. Это локальный сценарий демонстрации с проверками поведения, не подключённый к CI и не являющийся системой сравнения эталонных изображений.

Проверяется выбор трёх товаров клавиатурой, закрытие меню по Escape, раскрытие мобильного состава, взаимоисключение подсказок медовика и ответов FAQ, возврат из документов. Исходные данные и интерфейс сайта для съёмки не изменялись.

`verify-gallery.mjs` обновляет длинные снимки после прокрутки всех разделов и проверяет наличие файлов и фильтр галереи. `manifest.json` содержит перечень снимков, проверок и внешних ссылок.

В текущем рабочем дереве `bun.cmd run typecheck` и `bun.cmd run build` прошли успешно. Ранее запущенный сервер на порту 4321 оставлен работающим; браузеры, запущенные сценариями, закрыты.

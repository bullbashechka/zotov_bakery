# План работ: лендинг ZOTOV bakery

## Правила выполнения

- Этапы 1–15 выполняются последовательно.
- Перед началом каждого визуального блока заказчик выделяет актуальный фрейм в Figma.
- Каждый визуальный блок одновременно реализуется и проверяется в desktop- и мобильной версиях.
- Следующий блок начинается после согласования текущего или внесения согласованных исправлений.
- Для каждого этапа обязательны: диапазон ширины 320–1440 px, отсутствие горизонтальной прокрутки, доступность с клавиатуры, корректные состояния hover/focus/active, отсутствие ошибок в консоли и сохранение основного контента без JavaScript.
- После значимых изменений выполняются `bun run typecheck` и `bun run build` в объёме, достаточном для проверки этапа.
- Публикация на Cloudflare Pages не входит в задачи без отдельного разрешения.

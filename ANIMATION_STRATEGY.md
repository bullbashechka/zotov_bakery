# Анимации ZOTOV bakery — план реализации

## Принятый характер

Выразительное построчное появление текста из-под масок, плавное проявление десертов и рисование линии. Мелкие сдвиги и покачивания убраны после обратной связи: движение должно читаться как полноценное появление. Сцены проигрываются один раз и останавливаются. Без параллакса, фиксации секций, сглаживания всей страницы и постоянного движения.

Сохраняем контент, композицию и адаптивную вёрстку. «Ассортимент» и «Наша история» пока являются заглушками: добавляем только появление заголовков, не создаём новые разделы.

## Архитектура и доступность

- Первый экран использует отдельный `hero-motion.ts` с GSAP SplitText из уже установленного пакета GSAP. `mask: lines`, `autoSplit`, `aria: auto` и `reduceWhiteSpace: false` сохраняют доступность и неразрывные пробелы. После завершения возвращается исходный HTML заголовка. При медленных шрифтах или недоступном скрипте подготовительное состояние снимается через 1200 мс: контент не остаётся скрытым. Без JavaScript подготовительное состояние не включается. GSAP + ScrollTrigger управляют сценами при прокрутке. Реакции интерфейса остаются в CSS; новые зависимости не добавлены.
- `initPageMotion(root): () => void` и `data-motion-*` — внутренние интерфейсы. Модуль подключён только на главной; повторный вызов не дублирует обработчики, HMR вызывает очистку.
- IntersectionObserver учитывает обрезку горизонтальной каруселью. ScrollTrigger завершает покинутые сцены, включая пропущенные быстрым скроллом.
- Исходная разметка видима без JavaScript. На первом экране предусмотрена короткая подготовка к построчному появлению; фокус, нажатие, прокрутка более 80 px и reduced motion немедленно завершают сцену. В остальных сценах контент, уже находящийся на экране при инициализации, не скрывается. Декоративная линия первого экрана может начать рисование только в первую секунду начальной загрузки; при поздней загрузке скрипта остаётся видимой.
- При reduced motion GSAP возвращает исходные стили и завершает сцены; CSS-анимации сокращаются до мгновенного конечного состояния. Плавная прокрутка отключается.
- При фокусе раскрывается соответствующий элемент; фокус на контейнере карусели не раскрывает все скрытые карточки. Якорный переход завершает сцены целевой секции.
- Факт проигрывания сохраняется при изменении ширины. При возврате из bfcache сцены завершаются. Первый экран не переигрывается после завершения; во время появления SplitText учитывает изменение ширины.
- Позиционирование и движение разделены DOM-контейнерами. Один элемент не получает transform одновременно от CSS и GSAP. Особенно важно сохранить исходный transform торта, контактного заголовка и мобильных подсказок медовика.
- SVG-линии используют существующие stroke-контуры и stroke-dashoffset. Два раздельных участка средней мобильной линии преимуществ выделены в отдельные path без изменения геометрии.
- Нативные карусели и доступные details сохраняются. Для FAQ допускается анимация высоты; резервный таймер завершения — 320 мс при CSS-переходе высоты 240 мс.
